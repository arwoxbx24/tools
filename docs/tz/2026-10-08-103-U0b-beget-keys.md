# ТЗ dcfg-1ci20.11 U0b — `bin/beget-api`: ключи файла владельца `login`/`password`

Исполнитель пишет код сам, `code-channel` не вызывает. Разведка — repowise (для tools индекса нет → `grep -n`).

## Факт
`bin/beget-api user/getAccountInfo` → `missing BEGET_LOGIN|BEGET_API_PASSWORD in /root/workspaces/secrets/projects/beget.env; keys: login password password`.

## Правка (только `bin/beget-api`, одна-две строки)
Сразу после строки загрузки `. "$BEGET_ENV_FILE"` (до проверки missing):
```
BEGET_LOGIN=${BEGET_LOGIN:-${login:-}}
BEGET_API_PASSWORD=${BEGET_API_PASSWORD:-${password:-}}
```
Больше ничего не менять. Секреты не печатать. Файл секретов не трогать, не читать.

## Критерии приёмки
1. `bash -n bin/beget-api` → rc 0.
2. Мок (mktemp env-файл `login=u` / `password=p`, `BEGET_API` на несуществующий `http://127.0.0.1:9`): rc 2 (сеть), а не rc 3 (missing).
3. Живой вызов делает Claude.

## Паспорт источников
- Beget API: https://beget.com/ru/kb/api/obshhij-princzip-raboty-s-api — «параметры login + passwd»; ответ при ошибке — `error_text`, `error_code`.
- Факт ответа Beget 08.10: `"error_text": "Invalid request, login not provided"`.
