## U1 Факт

## U2 Правка (только 3 файла: `bin/ship-post`, `bin/ship-post-test`, `docs/ship-post-ARCHITECTURE.md`)
Классы (ADR-36):
- SUBMIT/автор: 10, 20, 24, 50, 80 — как сейчас (reopen + заметка).
- CI/автор: 40, 60 — как сейчас.
- 23 — как сейчас: молчаливый повтор, `return 0`.
- INFRA: 30, 70, 71, 75 и любой код вне таблицы — парковка.

1. `bin/ship-post`, `record_failure`:
   - `case $rc in 23|70|75) return 0 ;; esac` заменить на `case $rc in 23) return 0 ;; esac`.
   - Для кодов 10|20|24|40|50|60|80 оставить текущие ветки `case` и текущий хвост (reopen, заметка, `touch "$marker.reported"`) без изменений.
   - Ветку `30)` удалить из `case`. Для всех остальных кодов (бывшая ветка `*)` и 30/70/71/75) вызвать новую функцию `park_atom "$atom" "$head" "$rc" "$key" || return 1; touch "$marker.reported"; return 0` вместо reopen.
2. Новая функция `park_atom` рядом с `record_failure`:
```bash
park_atom(){
 local atom=$1 head=$2 rc=$3 key=$4 dir="$SHIP_POST_STATE_DIR/incidents" id='' st err
 mkdir -p "$dir/parked" || return 1
 [[ -f $dir/$rc ]] && id=$(<"$dir/$rc")
 if [[ -n $id ]]; then
  st=$(bd_cmd show "$id" --json 2>/dev/null | jq -r '.[0].status // empty' 2>/dev/null)
  [[ -n $st && $st != closed ]] || id=''
 fi
 if [[ -z $id ]]; then
  id=$(bd_cmd create "[ship-post] INFRA exit $rc" -t bug -p 0 -l contour:delivery --silent \
   -d "$(printf 'Курьер ship-post: отказ инфраструктуры доставки, код %s. Атомы запаркованы (метка delivery-blocked), курьер доставит их сам после починки.\n\n## Steps to Reproduce\nсм. заметки: атом, SHA, строка ошибки, лог квитанции\n\n## Acceptance Criteria\nпричина кода %s устранена; следующий проход курьера доставил атомы, метка delivery-blocked снята' "$rc" "$rc")") || return 1
  [[ -n $id ]] || return 1
  printf '%s\n' "$id" > "$dir/$rc.tmp" && mv "$dir/$rc.tmp" "$dir/$rc" || return 1
 fi
 if ! grep -qxF "$id $atom $head" "$dir/$rc.atoms" 2>/dev/null; then
  err=$(grep -v '^[0-9-]*T[0-9:+-]* actor=' "$key.log" 2>/dev/null | tail -1)
  bd_cmd update "$id" --append-notes "$atom $head ${err:-код $rc} $key.log" >/dev/null || return 1
  bd_cmd update "$atom" --add-label delivery-blocked >/dev/null || return 1
  bd_cmd update "$atom" --append-notes "доставка запаркована: инцидент $id, код $rc; агенту ничего не делать" >/dev/null || return 1
  printf '%s\n' "$id $atom $head" >> "$dir/$rc.atoms"
 fi
 printf '%s\n' "$id" > "$dir/parked/$atom" || return 1
 echo "ship-post: parked: $atom incident $id" >&2
}
```
