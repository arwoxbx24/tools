   v2 (09.10): без `=0` флаг `--fail-on-new-clones [<N>]` (`jscpd --help` 5.4.1) берёт `bin` как N → rc 2. Исполнено в рабочей копии U1 (ТЗ `2026-10-09-dcfg-sw0b3.1-one-task-per-cause.md#U3`, исправление `2026-10-09-dcfg-sw0b3.3-fix-flag.md`), перенесено сюда `git diff | git apply`.

Тест — во временной копии в `/tmp` (`git clone` локального репо или `git worktree add` в `/tmp`), не в этой рабочей копии. `rm -rf` вне `/tmp` запрещён. git commit в этой рабочей копии не делать.
