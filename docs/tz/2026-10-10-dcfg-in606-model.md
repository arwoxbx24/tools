# ТЗ dcfg-in606 — модель в итоговой строке канала

Разведка — repowise: `repowise symbol "bin/code-channel::run_form" --path /root/workspaces/tools` (finish() на :99–108).
Паспорт источников: `bin/code-channel:106` — `printf 'code-channel: mode=%s form=%s provider=%s precheck=%s run=%s t=%s\n'` — поля модели нет; при `--model` и продолжении на `resume_model` (:239) фактическая модель не видна (bd dcfg-in606, AE4 spec:035).

## U1 — `bin/code-channel`
1) В строку :106 добавить поле `model=%s` сразу после `provider=%s`, значение — `$model`.
2) В строке продолжения (`timeout 290 opencode run --session …`) перед вызовом присвоить `model=$resume_model`, чтобы итоговая строка показала модель продолжения.
Другой код не менять.

## U2 — `bin/code-channel-test`
Проверки, сверяющие итоговую строку целиком, обновить под новое поле (только ожидаемую строку). Новая проверка в конце: конфиг `$resume`, заглушка opencode 124 затем 0 → stderr содержит `model=opencode-go/mimo-v2.6-flash`. Итог — `PASS N/N`.

Не коммитить. Проверка (один прогон): `bin/code-channel-test` → все PASS, FAIL нет.

## v2 — причина: проверка 46 ложная
Строка продолжения `resume session=%s model=%s` (`:240`) печатает модель и без правки U1 → `grep model=…` в stderr проходит на старом коде. U1 в рабочем дереве уже сделан — не менять.
1. Проверка 46 сверяет именно итоговую строку: `grep -Eq '^code-channel: mode=code .* model=opencode-go/mimo-v2.6-flash precheck=' "$tmp/err"`.
2. Красный сначала: временно убрать `model=$resume_model` (U1 п.2), запустить `bin/code-channel-test` → `FAIL 46`; вернуть строку → `PASS 46/46`. В отчёт — обе строки вывода.
3. Условие на код возврата не убирать молча: какой rc даёт канал при заглушке `124,0` — написать в отчёт с выводом.
