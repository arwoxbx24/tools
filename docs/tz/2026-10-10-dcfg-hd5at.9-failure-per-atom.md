# ТЗ dcfg-hd5at.9 — ship-post: задача-сбой доставки на каждый атом

Цель: сбой доставки одного атома не блокирует другие атомы.
Рабочая копия: `/root/workspaces/tools/.worktrees/claude/dcfg-hd5at.9`. Пути указаны от неё.
Разведка — repowise (`repowise context bin/ship-post --path <рабочая копия>`; индекс tools обновлён на HEAD), затем `grep -n`; читать только правимый диапазон.

## Дефект
`bin/ship-post:265`: `t="[ship-post] delivery failure $(basename "$repo") exit $rc"`.
В заголовке нет атома. Поэтому:
- поиск в строках 266–267 находит одну общую задачу для всех атомов репозитория с тем же кодом;
- строка 272 (`bd dep add "$atom" "$issue"`) вешает её блокером на каждый такой атом.
Пример 10.10: одна задача dcfg-04jtb держит 7 атомов. Атом dcfg-hd5at.2 уже доставлен, но не закрывается, пока не влит чужой PR #181.

## Что сделать
1. В строке 265 добавить в заголовок атом: `t="[ship-post] delivery failure $(basename "$repo") $atom exit $rc"`. Больше в `bin/ship-post` ничего не менять.
2. `bin/ship-post-test`: добавить одну проверку. Два разных атома с одним репозиторием и одним кодом сбоя получают две разные задачи-сбоя, и у каждого атома блокер — только его задача. Существующие проверки не менять, кроме ожидаемых заголовков, если они проверяют старый формат.

## Проверка (вывод — в отчёт)
1) `bash -n bin/ship-post` → rc 0
2) `bash bin/ship-post-test` → все PASS, включая новую проверку
3) `git diff --numstat -- bin/ship-post` → `1	1	bin/ship-post`
4) `git status --short` → только `bin/ship-post`, `bin/ship-post-test` и этот ТЗ

## Паспорт источников
- Внешних вызовов нет. В тестах bd — только мок теста, реальный bd не вызывать. Вызов вне паспорта или вторая ошибка подряд → status blocked.

## Правила исполнителя
- Минимальный diff, KISS/YAGNI. Не делать git add/commit. Не вызывать code-channel, opencode run, codex exec, реальный bd, gh, git push. Ветки не трогать.
- Запрещено: rm -rf вне /tmp, chmod -R, ~/.ssh, iptables, curl|bash, глобальные пакеты, чтение секретов (`/root/workspaces/secrets/**`, `auth.json`, `~/.codex/*.toml`).
