2. Code: потолок первой попытки всегда 590 с. Удалить строку `[[ -n $resume_model ]] && tmo=290` и весь блок продолжения сессии после rc 124 (`if [[ $mode == code && $run == 124 && -n $resume_model ]] … fi`). Переменная `tmo` больше не нужна — `timeout 590`.
3. rc 124 формы `go` → как сейчас: запись в журнал (с `session`) и выход 124 без перехода на codex. Схему конфига (`resume_model` допустим) и чтение `resume_model` для проверки `--model` не трогать.
