# TZ v4 — auto-submit refused under --watch (atom dcfg-74h33.7)

Причина v4: живой курьер запущен как `ship-post --watch` (pm2 id 97), поэтому `watch=1`. `auto_submit_scan` вызывает `do_submit`, а `do_submit` останавливается на `bin/ship-post:206` с `usage_err "--submit cannot be combined with --watch or --dry-run"`. Строка видна в pm2 log на каждом проходе; `ship-post --status dcfg-74h33.3` показывает `none`. AS1–AS6 запускали курьер без `--watch`, поэтому тесты это не поймали.

## U1
Файлы: `bin/ship-post`, `bin/ship-post-test`.
1. `bin/ship-post`, функция `auto_submit_scan`, ~строка 734: в подшелле перед `do_submit` добавлен `watch=0` — подшелл локализует изменение; явный отказ CLI `--submit --watch` на строке 206 остаётся без изменений.
2. `bin/ship-post-test`, функция `test_auto_submit`: добавлен кейс AS7 после AS6 — копия сетапа AS1 (`setup_submit auto7 claude/dcfg-auto.7`, файл file.txt, статус closed, reason `done`), но курьер запускается с `--watch`; PASS когда HEAD изменился, вывод содержит `auto-submit dcfg-auto.7` и не содержит `cannot be combined`.
