## Зачем
Возраст записи /tmp — mtime верхнего уровня; у папки он не меняется, когда процесс дописывает уже существующий файл внутри. Сейчас исключается только cwd живого процесса (`scripts/disk-rotate.sh:365-381`), значит папку с открытым на запись файлом (процесс работает из другого cwd) уборка удалит — потеря живой работы.

## Правка `scripts/disk-rotate.sh` (только функция `cleanup_tmp`)
1. Рядом с проходом по `/proc/[0-9]*/cwd` (`:368`) — тем же одним проходом до цикла собрать цели открытых дескрипторов: `/proc/[0-9]*/fd/*` → `readlink`; брать только цели, начинающиеся с `"$DR_TMP_ROOT/"`; хранить верхний уровень (`$DR_TMP_ROOT/<имя>`) в ассоциативном массиве (без дублей; без вложенного цикла по всем fd на каждого кандидата).
2. В цикле кандидатов пропускать запись, если её путь есть в этом массиве (так же, как живой cwd).
3. Ошибки чтения `/proc` (процесс исчез, нет прав) — молча пропускать. Остальная логика, лимиты, исключения по имени, `safe-delete` — без изменений.
