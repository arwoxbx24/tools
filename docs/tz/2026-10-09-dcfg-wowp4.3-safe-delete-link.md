# ТЗ dcfg-wowp4.3 — safe-delete: режим `link` для висящих симлинков

## U1 — режим `link`
Разведка — repowise; индекс: repowise/CBM проверен, нет — `tools/bin/code-memory-enable`.

Причина: в `~/.claude/agents` три висящих симлинка (`analyst.md`, `orchestrator.md`, `pm2-executor.md` → удалённые `projects/.claude/agents/*`). `safe-delete file` их не берёт: `realpath -e` (`bin/safe-delete:27`) падает на висящей ссылке, `/root/.claude/agents` нет в корнях (`:28`). Голый `rm` — deny.

Решение (ADR): новая ветка `link)` в `case "$cmd"` файла `bin/safe-delete`, рядом с `file)`. Режим `file` не менять.

Поведение `safe-delete [--bk <каталог>] link <путь>`:
1. Нет аргумента → `refuse 'usage'` (код 2).
2. `<путь>` не симлинк (`[[ -L ]]` ложно) → `refuse "не симлинк: <путь>"` (код 2).
3. Цель ссылки существует (`[[ -e ]]` истинно) → `refuse "симлинк живой: <путь>"` (код 2). Удаляются только висящие.
4. `p` = `realpath -e` каталога ссылки + `/` + имя ссылки. Нет каталога → `refuse`.
5. Корни: `${SAFE_DELETE_ROOTS:-/root/.claude/agents}`. Если `SAFE_DELETE_ROOTS` задан — каждый корень обязан быть под `/tmp/` (та же проверка, что в `file`). `p` вне корней → `refuse "вне разрешённых корней: <p>"`.
6. `t=$(readlink -- "$p")`; `log link "$p" - - "$t" - backup-ok`; `rm -- "$p" || exit 1`; `log link "$p" - - "$t" - deleted`; `exit 0`. Восстановление — `ln -s <t> <p>` по строке журнала.
7. Строку usage (`:11`) дополнить словом `link`.

Тест — `bin/safe-delete-test`, перед итоговой проверкой счётчика:
- T22: висящий симлинк в `$d` → `safe-delete --bk "$bk" link` rc 0, ссылки нет (`[[ ! -L ]]`), в `$bk/ledger.tsv` есть строка `link` с `deleted`.
- T23: обычный файл и живой симлинк в `$d` → `link` rc 2, оба на месте.
- Итог `[[ $ok == 21 ]]` → `[[ $ok == 23 ]]`.

Запреты: только `bin/safe-delete` и `bin/safe-delete-test`; не трогать корни режима `file`; не добавлять `/root/.claude` целиком (T18); `rm -rf` запрещён; без новых зависимостей. Принципы: KISS, YAGNI, fail fast.

Критерии:
1. `bash -n bin/safe-delete` rc 0.
2. `bin/safe-delete-test` → последняя проверка проходит, `PASS T22`, `PASS T23`, rc 0.
3. `grep -c 'link)' bin/safe-delete` → 1.

Паспорт источников: `bin/safe-delete:25-51` (режим `file`, журнал `log`), `bin/safe-delete-test:6,126-154` (корни теста, T18, счётчик); прецедент узкого корня `.claude` — коммит `dc0cbbe` (spec:091).
