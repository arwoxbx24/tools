# ТЗ dcfg-tdd86.3 — запрет коммита исполнителю во всех формах канала

Разведка — repowise: `repowise symbol "bin/code-channel::run_form" --path /root/workspaces/tools` (функция run_form).
Паспорт источников: в `bin/code-channel` три строки-префикса промпта («Ты уже исполнитель внутри code-channel…», «Не создавай и не переключай ветки; не делай git add и git commit — коммит делает оркестратор», «Не вызывай bd: трекер ведёт оркестратор») стоят внутри `if [[ $id == codex ]]; then` в run_form, поэтому формы opencode (go и др.) их не получают. Факт бага (bd dcfg-tdd86.3): исполнитель opencode закоммитил dbbbb03 без трейлеров, ship-post отказал. Решение FR-023 spec:035: исполнитель не коммитит.

## U1 — `bin/code-channel`
Перенести эти три строки `prompt=$(printf …)` без изменения текста из блока `if [[ $id == codex ]]` в run_form прямо перед строкой `if [[ $id == codex ]]; then`, чтобы префикс получали все формы. Другой код не менять.

## U2 — `bin/code-channel-test`, проверка 41 в конце
Форма go (конфиг `$go`), заглушка opencode rc 0 пишет свои аргументы в `$log` (как в существующих проверках) → `$log` содержит `не делай git add и git commit`. Проверки 1–40 не менять; итог — `PASS 41/41`.

Не коммитить. Проверка (один прогон): `bin/code-channel-test` → `PASS 41/41`, FAIL нет.
