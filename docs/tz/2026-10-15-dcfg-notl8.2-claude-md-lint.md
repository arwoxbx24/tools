Create exactly two files (bash, `#!/usr/bin/env bash`, `set -u`, chmod +x), style like `bin/where` / `bin/where-test`:

1. `bin/claude-md-lint [root]` — root default `/root/workspaces/projects`.
   - `--help` / `-h`: one `usage:` line on stdout, rc 0, no other action (tools contract).
   - Files: `find "$root" -maxdepth 4 -name CLAUDE.md`, excluding paths containing `/node_modules/`, `/.git/`, `/.worktrees/`, `/.agent-work/`.
   - Per file:
     - `lines` = line count; over-limit when > 200 (Anthropic: "target under 200 lines per CLAUDE.md file").
     - `dup` = count of non-empty lines of at least 20 chars that appear verbatim (whole line, after trimming spaces) in any ancestor instruction file: every `CLAUDE.md` in parent directories of the file up to `/`, plus `$HOME/.claude/CLAUDE.md` and `/etc/claude-code/CLAUDE.md` if readable. The file itself is not its own ancestor.
     - `broken` = count of `@path` imports whose target does not exist. An import is a token starting with `@` followed by a path containing `/` or `.`, at line start or after a space. Skip text inside fenced code blocks (``` lines) and inside backtick spans. Resolve relative to the file's directory; `~/` → `$HOME/`.
   - Output: for each file with lines>200 or dup>0 or broken>0 print `WARN <path> lines=<n> dup=<d> broken=<b>`; last line always `files=<N> over200=<a> dup_files=<b> broken_imports=<c>`.
   - rc 0 after a completed report; rc 2 when root is not a directory (message on stderr). Writes nothing anywhere (read-only).
