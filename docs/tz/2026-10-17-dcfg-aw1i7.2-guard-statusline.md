## Part A — goal-guard (dcfg-z2zdr)
Facts: `bin/goal-guard` reads `.background_tasks` from the Stop input (line with `bg=$(jq -er 'if ((.background_tasks // [])` …) and then re-derives running tasks from transcript text (the block starting `tp=$(jq -er '(.transcript_path // "")'` through the matching `fi`, which seds `Task ID:` / `agentId:` / `<task-id>`). Any transcript that quotes such text in tool output yields a bogus active id → exit 0, no block.
Official source: code.claude.com/docs/en/hooks, Stop input: "The `background_tasks` and `session_crons` arrays let hooks distinguish "session is done" from "session is paused waiting for background work to wake it back up". Both arrays are present when the task registry is reachable and are empty when nothing is in flight or scheduled." Task types include `shell`, `subagent`, `monitor`, `workflow`.
Required:
1. Delete the transcript block (tp read + sed/awk + `[ -z "$active" ] || exit 0` + its `fi`). `background_tasks` is the only source.
2. `background_tasks` absent (not present in the input) → `exit 0` (registry unreachable = unknown, do not block); present and non-empty → `exit 0` (as today); present and empty → continue (as today).
3.
