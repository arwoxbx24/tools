# TZ — broken worktree link is a skip (atom dcfg-c75sy.4)

Plan: projects `docs/tz/2026-10-16-dcfg-c75sy-ship-post-parked-loop.md` U2 (R4, KTD2). Разведка — repowise (codebase-memory `search_graph`/`get_code_snippet`), затем `grep -n`; Read только правимых диапазонов. Индекс: repowise/CBM проверен, нет — `tools/bin/code-memory-enable`.

Причина: у рабочей копии из `git worktree list --porcelain` файл `$wt/.git` содержит `gitdir: <путь>`, а этого пути нет. Тогда `git -C "$wt" log -1` на `bin/ship-post:600` печатает `fatal: not a git repository: ...` и считает `failed++` на каждом проходе (живой лог: `failed=3 skip=3`).

## U2
Файлы: `bin/ship-post`, `bin/ship-post-test`. Других файлов не трогать.
1. `bin/ship-post`, перед строкой 600 (после проверки `-f $wt/.git` на строке 599): прочитать цель из строки `gitdir:` файла `$wt/.git`; если этого пути нет → `echo "skip $wt broken worktree link"; skip=$((skip+1)); continue`. Остальные ошибки `git log` на строке 600 по-прежнему `failed++` (stderr не глушить).
2. `bin/ship-post-test`: новая функция `test_broken_link` по образцу соседних (`make_repo`, `make_worktree`, `run_tool`), вызвать её в группе `all` и добавить группу `SHIP_POST_TEST_GROUP=broken` в селектор (~строка 860-890):
   - BL1: рабочая копия создана `make_worktree` (её по-прежнему видно в `git worktree list --porcelain`), затем `$wt/.git` перезаписан строкой `gitdir: /nonexistent/path` → вывод содержит `skip <wt> broken worktree link`, stderr не содержит `fatal:`, итоговая строка `failed=0`.
   - BL2: здоровая рабочая копия в том же репо по-прежнему обрабатывается (как в соседних тестах).

## U2 v2 (16.10, дефект приёмки)
Причина: правка `bin/ship-post:600-601` проверяет `-e $gd` относительно текущего каталога. Git принимает относительный `gitdir:` относительно каталога файла `$wt/.git` (замер git 2.43: `gitdir: ../a/.git/worktrees/b` → `git -C b log -1` выдал коммит). Такая исправная копия сейчас ошибочно считается битой и не доставляется. Плюс `gd` не объявлена `local` в `scan_repo` (строка 588 объявляет все переменные функции).
1. `bin/ship-post:588`: добавить `gd` в строку `local`.
2. `bin/ship-post:600-601`: относительный путь (не начинается с `/`) проверять от `$wt` (`[[ $gd == /* ]] || gd=$wt/$gd`), абсолютный — как сейчас.
3. `bin/ship-post-test`, `test_broken_link`: BL3 — исправная рабочая копия, у которой `$wt/.git` переписан на относительный путь к тому же gitdir (`gitdir: <относительный путь от $wt к $d/.git/worktrees/<имя>>`), обрабатывается: нет строки `broken worktree link` для неё, один вызов `--atom <её атом> ` в `ship.calls`. Red-first: до п.2 BL3 падает.
