# ТЗ dcfg-8yqv4.22 — ship-post --submit: конфликт с базой отклоняется сразу (spec:099 v6 U14, FR-034, ADR-27)

## U14
Спека: `/root/workspaces/projects/specs/099-ship-dev-prod/spec.md` §«v6» — прочитать раздел целиком до правки, включая «Таблицу кодов».

Причина: конфликт ветки с `origin/<base>` сейчас обнаруживает курьер асинхронно (`bin/ship` → код 50, финальный), когда агент уже ушёл. Нужно ловить его при сдаче, в сессии агента.

Правка в `bin/ship-post`, функция сдачи (`--submit`, `do_submit`): после всех текущих проверок и до записи в очередь/bd:
1. База: `read -r _ base _ <<< "$(ga_base "$wt_real")"` (тот же источник, что `bin/ship:60`).
2. `git -C "$wt_real" fetch -q origin "$base"` — ошибка → stderr `ship-post: fetch origin/<base> failed`, exit 70.
3. `files=$(git -C "$wt_real" merge-tree --write-tree --name-only "origin/$base" HEAD)`; rc 1 → stderr `ship-post: conflict with origin/<base>: <файлы через пробел, без первой строки-дерева>` и вторая строка `ship-post: fix: git -C <wt> fetch origin && git -C <wt> merge origin/<base>; resolve files; test; bd close; submit again`; exit 50. Очередь, квитанции и bd не трогать.
4. rc 0 → поведение прежнее.
Проверить, что `git merge-tree --write-tree` есть в установленной версии git (`git --version`, `git merge-tree -h`), — в отчёт.

`bin/ship-post-test`: два теста: (а) ветка, конфликтующая с `origin/main` по одной строке файла → `--submit` rc 50, имя файла в stderr, в состоянии курьера ничего не появилось; (б) чистая ветка → прежний результат. Тест (а) падает на старом `bin/ship-post` (из `git show origin/main:bin/ship-post`) и проходит на новом — проверить и написать в отчёте.

`docs/ship-post-ARCHITECTURE.md`: одна строка — `--submit` отклоняет конфликт с базой кодом 50 до очереди (ADR-27).

Не менять: `bin/ship`, `bin/ship-promote`, `record_failure` (это атом .23).

Критерии (исполнитель запускает сам и прикладывает вывод):
1. `bash -n bin/ship-post` → rc 0.
2. `bash bin/ship-post-test` → `failures=0`, rc 0; новые тесты PASS; тест (а) FAIL на старом коде.
3. `bash bin/ship-doc-check origin/main` → rc 0.
4. Коммит не делать — отчёт: дифф `--stat` и выводы команд.
