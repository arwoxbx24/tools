# ТЗ dcfg-8yqv4.30 — scan_repo не ждёт доставки (spec:099 v6 ADR-34)

## U19
Разведку не делать широко — якоря даны. Править ТОЛЬКО `bin/ship-post` (`scan_repo`, строки 484–489), `bin/ship-post-test` (`test_adr30`), одну строку `docs/ship-post-ARCHITECTURE.md` §3 п.4 (фраза «and waits for all of them»).

Замер 10.10: worker репо (`bin/ship-post:526-536`) синхронно вызывает `scan_repo`; `scan_repo` после запуска фоновых `deliver_one` ждёт их все (строка 487) под `flock` репо. Пока одна доставка ждёт CI (~4 мин), новые сданные атомы репо не берутся.

Правка:
1. Строка 485: фоновая доставка под неблокирующим замком атома: `( exec {fd}>&-; exec {afd}>"$lk.$atom"; flock -n "$afd" || exit 0; BEADS_ACTOR=$actor; deliver_one "$wt" "$atom" "$tz" "$head" "$repo" "$branch" ) &` — `$lk` уже есть (замок репо). Первым делом ребёнок закрывает fd замка репо, иначе замок репо держится до конца доставки. Атом уже доставляется (замок занят) → тихий выход 0 без второго `ship`.
2. Строку 487 (`for p in "${pids[@]}"; do wait …`) удалить; `pids` больше не нужен. Лимит строки 484 (`SHIP_POST_JOBS`) оставить.
3. Строка 489: `echo "ok=$ok failed=$failed skip=$skip started=$started"`, где `started` — число запущенных фоновых доставок (ok/failed больше не считают фоновые; каждая доставка сама пишет свой итог через квитанции и `record_failure`).
4. ARCHITECTURE §3 п.4: «and waits for all of them» → «without waiting for them; a per-atom lock `<repo lock>.<atom>` prevents a second concurrent delivery of the same atom (ADR-34)».

`test_adr30`: (а) проход возвращается < 1500 мс при `MOCK_SHIP_DELAY=2`, в выводе `started=3`; (б) дождаться (до 5 с) трёх строк в `ship.calls`; (в) второй проход сразу после первого (пока ship спит) не добавляет вызовов `ship` сверх 3.
Проверка (вывод в отчёт): `bash -n bin/ship-post bin/ship-post-test`; `SHIP_POST_TEST_GROUP=adr30` → `failures=0`; `SHIP_POST_TEST_GROUP=u15` → `failures=0`; `SHIP_POST_TEST_GROUP=recovery` → `failures=0`. Полный набор НЕ запускать.
Запреты: другие файлы; git commit/push; `rm -rf`; секреты не читать.
