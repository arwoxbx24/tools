Skills: prod, ponytail. Разведка — repowise: индекс проверен, репозиторий tools не в индексе (`list_repos` → только projects) → `grep -n` по точным именам, `Read` только правимых диапазонов.
Правишь только: `bin/code-channel`, `bin/code-channel-test`.

## U1 — модель только из конфига (FR-032)
Сейчас `bin/code-channel:57` `model=${override:-$model}` принимает любую `--model`.
Сделать: если `override` не пуст и не равен ни `model`, ни `resume_model` записи формы в конфиге (`entry_for "$id"`, ключ `resume_model` необязательный, по умолчанию пусто) → `fail "модель не в конфиге: $override"` и код 3. Схему проверки конфига в `:9` дополни: `(.resume_model? // "") | type == "string"`.

## U2 — продолжение той же сессии при rc 124 (FR-026)
Сейчас `:226` `timeout 590 opencode run --title "$id_run" -m "$model" "$prompt"; run=$?`, затем `:228` `reconcile "$run"`.
Сделать — только для этой ветки (режим code, opencode-формы), между `:226` и `:228`:
- если `run == 124` и `resume_model` записи не пуст: id сессии — тем же запросом `sqlite3 -readonly`, что в `reconcile` (`:82`, по `title='$id_run'`), но `select id`;
- id найден → одна строка в stderr `code-channel: resume session=<id> model=<resume_model>` и `timeout 590 opencode run --session "<id>" -m "<resume_model>" "Продолжи ТЗ с места остановки: доделай только невыполненное, сделанное не переделывай."; run=$?`;
- id не найден или `resume_model` пуст → поведение как сейчас.
Один повтор, без цикла. Потолок 590 не менять. `reconcile` после продолжения сверяет провайдер как обычно.

## U3 — тест (`bin/code-channel-test`, тем же способом, что существующие проверки с заглушкой `opencode` в `PATH`)
1. `--model` не из конфига → rc 3 и «модель не в конфиге».
2. Заглушка `opencode` возвращает 124 на первый вызов, 0 на второй; в конфиге теста `resume_model` задан → второй вызов заглушки получил `--session` и `-m <resume_model>` (лог заглушки), строка `code-channel: resume session=` в stderr, итог rc 0.
3. `resume_model` пуст → второго вызова нет, rc 124.
4. Существующие проверки (в т.ч. reconcile rc 23, проверки 12 и 26) остаются зелёными; если существующая проверка передаёт `--model`, которого нет в её тестовом конфиге, — добавь модель в тестовый конфиг этой проверки, не ослабляя проверку.
Прогон один раз: `bin/code-channel-test` → rc 0.
