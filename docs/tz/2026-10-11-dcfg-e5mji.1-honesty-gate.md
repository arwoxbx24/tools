План: projects `docs/plans/2026-10-11-e5mji-honesty-gate-plan.md` (U1, U2). Разведка — repowise; индекс: repowise/CBM проверен, нет — `tools/bin/code-memory-enable`.
Принципы: KISS, YAGNI, fail fast на входе; без комментариев к неизменённому коду; без новых зависимостей (bash, jq, awk, bd).
Запреты: не трогать другие файлы, не запускать `bd create/update/close` (тесты bd делает оркестратор), не читать секреты, `rm -rf` нельзя.

## U1 — новый файл `bin/bd-ac-split` (исполняемый, bash, ≤60 строк)
- `bd-ac-split --help|-h` → usage на stdout, rc 0, без действий. Без аргумента или >1 аргумента → usage в stderr, rc 2.
- `bd-ac-split <id>`: `bd show <id> --json | jq -r '.[0].acceptance_criteria // ""'`. Пункты — нумерация `N)` или `N.` в начале текста или после пробела/перевода строки, N строго подряд 1, 2, 3…; токен с другим номером (например «(2)» внутри пункта 1) остаётся текстом текущего пункта (пример: `1) a 2) b` → [«a», «b»]; `1. x\n2. y` → [«x», «y»]; `1) rc 0 (5) вывод 2) b` → [«rc 0 (5) вывод», «b»]). Текст пункта обрезать по краям, до 200 символов.
- Меньше 2 пунктов → печать `ok=0 skip=0 (criteria<2)`, rc 0; если acceptance непустой — строка-предупреждение в stderr.
- Существующие дети: `bd list --parent <id> --limit 0 --json | jq -r '.[].title'`. Ребёнок с заголовком, начинающимся с `[AC<N>]`, уже есть → skip.
- Иначе: `bd create "[AC<N>] <текст>" --parent <id> -t task --silent -d "Критерий <N> атома <id>" --acceptance "1) <текст>"`. Отказ одного create → строка в stderr, продолжить; в конце rc 1.
- Итог stdout: `ok=<созданных> skip=<пропущенных>`; rc 0, если отказов нет.

## U2 — `bin/goal-guard` (файл уже в worktree, = 5ef852f; правка ≤15 строк)
Вставить после строки 27 (проверка потолка `count >= max`), до строки 28 (`ids=$(cd /root/workspaces/projects …`):
- `neg=` есть строка `msg`, совпадающая с `^[[:space:]]*((🔴|⚠️|❌|🟡)[[:space:]]*)?(\*\*)?((Статус|Status|Итог|Result):[[:space:]]*)?(\*\*)?(PARTIAL|BLOCKED|UNVERIFIED|FAILED)(\*\*)?([:.,—-]|[[:space:]]|$)` (статус в начале строки; маркеры списка `-`, цитаты `>`, кавычки `«` перед словом — не совпадают). Регекс держать в переменной (`re=…; [[ $l =~ $re ]]`), не в литерале.
- `routes=` число строк, совпадающих с `^[[:space:]]*(Маршрут|Route):.*→[[:space:]]*[^[:space:]]` (непустой итог после `→`).
- `neg` и `routes < 2` → записать счётчик как в строке 30 и вывести `jq -nc --arg r "goal-guard: негативный статус без маршрутов восстановления — допиши строки «Маршрут: <что сделал> → <итог>» (≥2) или продолжай работу." '{decision:"block",reason:$r}'`, exit 0.
- Иначе — прежняя логика без изменений. Строки 1–27 и 28–33 не менять (кроме сдвига номеров). Fail-open (`exit 0` при ошибке) сохранить.
