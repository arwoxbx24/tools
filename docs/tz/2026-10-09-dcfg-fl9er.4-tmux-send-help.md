# ТЗ dcfg-fl9er.4 — tmux-send: справка без отправки

## U1 — `--help`/`-h` печатает usage и выходит 0
Разведка — repowise; индекс: repowise/CBM проверен, нет — `tools/bin/code-memory-enable`.
Причина (факт 09.10): `bin/tmux-send --help` принял `--help` за target, отправил пустой текст и вышел 1 «expect 'Working' not matched». Закон переводится на `tmux-send` (dcfg-9dezt) — агенты по правилу «ДОКУМЕНТАЦИЯ ПЕРВОЙ» вызовут `--help` первым.

Правка `bin/tmux-send` — одна вставка ПЕРЕД строкой 6 `target=${1:-}`:
```bash
case ${1:-} in -h|--help) echo "usage: tmux-send <target> '<текст>' [--expect '<regex>']  (env TMUX_SEND_SOCKET, TMUX_SEND_SLEEP; до 3 повторов Enter, rc 0 — ожидание найдено, 1 — нет, 2 — ошибка tmux)"; exit 0;; esac
```
Больше ничего в файле не менять.

Тест `bin/tmux-send-test` — добавить один кейс в стиле существующих: `bin/tmux-send --help` → rc 0, вывод содержит `usage:`, и `tmux` не вызывался (если тест подменяет tmux через PATH-заглушку — заглушка не получила вызова).

Проверка: `bin/tmux-send-test` → rc 0; `bin/tmux-send --help` → rc 0 и строка `usage:`.
Принципы: KISS, YAGNI — без парсера аргументов.
