# ТЗ dcfg-hd5at.7 — сообщение при явном вызове выключенного провайдера

Рабочая копия: `/root/workspaces/tools/.worktrees/claude/dcfg-hd5at.6`. Пути указаны от неё.
Разведка — repowise; читать только строки, указанные ниже.

## Дефект
`bin/code-channel:46`: `enabled=$(entry_for "$form" | jq -er '.enabled') || exit 3`.
Если `enabled` равно `false`, `jq -e` возвращает rc 1. Скрипт выходит с кодом 3 молча. Строка `провайдер $form выключен в конфиге` не печатается.

## Что сделать
1. В строке 46 заменить `jq -er` на `jq -r`. Других правок в `bin/code-channel` нет.
2. В `bin/code-channel-test` добавить одну проверку (34):
   - явный вызов выключенного провайдера → rc 3;
   - stderr содержит `выключен в конфиге`.
   Финальная строка теста: `PASS 34/34`.

## Проверка (вывод — в отчёт)
1) `bash bin/code-channel-test` → `PASS 34/34`
2) `git diff --numstat -- bin/code-channel` → `1	1	bin/code-channel`

## Паспорт источников
- jq 1.7, флаг `-e`: `jq --help` — «-e, --exit-status set exit status code based on the output». Замер bin-bf 10.10: вывод `false` → rc 3, stderr 0 байт.
- Других внешних вызовов нет. Вызов вне паспорта или вторая ошибка подряд → status blocked.
