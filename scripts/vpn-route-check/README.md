# vpn-route-check

Проверка маршрутов VPN (Clash Verge Rev / Hiddify для Windows 10/11). Скрипт прогоняет контрольный список сайтов (РФ и зарубежные), читает из журнала ядра, по какому правилу и в какую группу ушёл каждый сайт, меряет время ответа, 60 секунд пассивно записывает маршруты обычного сёрфинга, сохраняет отчёт на рабочий стол и отправляет его на сервер.

## Как запустить

1. Включите VPN-программу.
2. Дважды щёлкните `START.cmd`.
3. Подождите 1–2 минуты и не закрывайте окно. Когда скрипт скажет «Теперь 60 секунд просто ходите по своим обычным сайтам», откройте браузер и походите по привычным сайтам.

## Что уходит на сервер

Только имена хостов, правило, группа и миллисекунды. Паролей, cookie и содержимого трафика нет.

## Где отчёт

На рабочем столе: `vpn-route-check-<дата-время>.json`. Файл остаётся, даже если отправка не удалась. Отправка идёт, только если рядом со скриптом лежит `upload.json`.

## TUN-режим

Поле `direct_ms` — замер напрямую, мимо прокси. В режиме TUN этот трафик всё равно идёт через ядро и попадает под его правила, поэтому `direct_ms` не показывает «чистое» время без VPN.

## Для агента

Прочитать результат:

```
mc cp b244share/files/vpn-route-check/result.json .
```

Сгенерировать `upload.json` (поля формы берутся из `share`):

```
mc share upload --json --expire 72h b244share/files/vpn-route-check/result.json
```

Самопроверка разбора (без сети):

```
pwsh -File vpn-route-check.ps1 -SelfTest
```
